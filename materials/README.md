# Материалы ВКР

Индекс документов. Код и документация инструмента живут в `crates/` и `docs/`;
здесь — исходные материалы и план.

| Файл | Что внутри |
|---|---|
| [`roadmap.md`](roadmap.md) | **Главный план работ**: архитектура, фазы 0–13, DoD, тесты, эксперименты, риски. Единственный источник истины по порядку работ. |
| [`analysis.md`](analysis.md) | Исходный анализ ниши, обоснование open source, цель и задачи ВКР. |
| [`rules_catalog.md`](rules_catalog.md) | Каталог правил (backlog): ID, условия, severity, профили, приоритеты, риск ложных срабатываний. |
| [`source_list.md`](source_list.md) | Список изученных источников по теме. |
| [`notes.md`](notes.md) | Заметки и идеи, возникшие при чтении источников. |

**С чего начинать:** открыть `roadmap.md`, раздел «Прогресс», и идти по первой
незакрытой фазе. Перед реализацией фазы прочитать её шаги и DoD целиком.
